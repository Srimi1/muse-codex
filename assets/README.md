# Brand assets

| Asset | Purpose |
| --- | --- |
| `muse-codex-logo.png` | Transparent primary mark for the README and project identity |
| `muse-codex-social-preview.png` | 1280 x 640 repository social preview |

The mark is an original visual identity for Muse Codex. Its abstract `M`, code
chevrons, and central spark represent the Muse host, the compatibility gateway,
and model-backed creation. It intentionally does not reproduce Meta or OpenAI
corporate marks.

Use the full mark with generous clear space. Do not recolor it to imitate a
third-party brand or present it in a way that suggests endorsement by Meta or
OpenAI. Unless stated otherwise, these assets are distributed under the
repository's [Apache License 2.0](../LICENSE).
