# Support

Muse Codex is experimental, source-only software maintained on a best-effort
basis. There is no guaranteed response time or commercial support commitment.

## Before asking for help

Confirm that your environment matches the supported baseline:

- Apple-silicon macOS;
- Muse Code exactly `1.0.3-R2198.1`; and
- a source build from the latest `main` commit.

Then review [installation](docs/INSTALLATION.md),
[configuration](docs/CONFIGURATION.md), and the
[known compatibility limits](README.md#known-limits).

## Where to ask

- Use [GitHub Discussions](https://github.com/Srimi1/muse-codex/discussions)
  for setup questions and usage help.
- Use the [bug report form](https://github.com/Srimi1/muse-codex/issues/new?template=bug_report.yml)
  for a reproducible defect.
- Use the [feature request form](https://github.com/Srimi1/muse-codex/issues/new?template=feature_request.yml)
  for a scoped proposal.
- Use [private vulnerability reporting](https://github.com/Srimi1/muse-codex/security/advisories/new)
  for suspected security issues.

Redact credentials, prompts, private URLs, user data, and proprietary Muse
content from every report. The project cannot support modified Muse binaries,
unsupported host versions, or unofficial binary distributions. Issues caused
solely by third-party plugins or hooks should be reported to their maintainers;
Muse Codex preserves Muse's extension path but does not own those extensions.
